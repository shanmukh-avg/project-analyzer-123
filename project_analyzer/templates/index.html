Project Documentation

Project Analyzer helps students check their project information, requirements, and completeness.

Key Features

  • Project information analysis
  • Project completeness checking
  • Basic Python code statistics and suggestions
  • Downloadable analysis reports

Technologies Used

HTML, CSS, JavaScript, Python, Flask and SQLite.

Source Code

The source code is maintained in your Project Analyzer project files.

  • app.py — Python Flask backend
  • templates/index.html — Website structure
  • static/style.css — Website styling
  • static/script.js — Frontend JavaScript
  • requirements.txt — Python dependencies

Open these files in VS Code to view the source code.
